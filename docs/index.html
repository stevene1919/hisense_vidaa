Hisense VIDAA TV Integration

100% Local Push Smart TV Integration for Home Assistant

A native, zero-cloud Home Assistant custom integration for Hisense and VIDAA OS smart TVs. Connects directly to the TV's internal hardware MQTT broker over TLS (port 36669), delivering instantaneous state feedback, media controls, app launching, on-screen notifications, and remote navigation with zero external bridges or cloud dependencies.

Key Features

  • 100% Local LAN Control (iot_class: local_push): Communicates directly with the TV's internal broker over your local network. Supports IoT VLANs with WAN access blocked.
  • Native Python Cryptography: All challenge-response handshake algorithms and 64-bit XOR transformations run in pure native Python with zero binary library dependencies.
  • Media Player Platform: Full power toggle, volume stepping, input source switcher, dynamic app artwork, deep linking, and transport controls. Exposes MediaPlayerDeviceClass.TV for Apple HomeKit / Control Center integration.
  • Dedicated Remote Platform: High-speed key command dispatching, key aliases (home, menu, back, ok), and customizable burst repetitions.
  • Picture & Sound Modes: Fine-tune Backlight, Brightness, and Contrast sliders, and switch picture modes (Cinema, Dynamic, Filmmaker, Game) and equalizer presets.
  • On-Screen Toast Notifications: Send custom alert banners and toast messages directly to the TV screen via notify.send_message.
  • Direct Virtual Keyboard Text Input: Inject text into active on-screen search bars and browser input fields with send_text_input.
  • Subnet-Directed Wake-on-LAN: Dual-MAC fallback (Ethernet + Wi-Fi) with standby token renewal for Fast Power On / Quick Start models.
  • Multi-Language Localization: Native translations for English, Italian (it), Spanish (es), German (de), French (fr), and Portuguese (pt, pt-BR).

Frequently Asked Questions

What is the Hisense VIDAA TV integration?
It is a native custom integration for Home Assistant that communicates directly with Hisense smart TVs running VIDAA OS over your local network using MQTT over TLS (port 36669). It requires zero cloud accounts, external bridges, or internet dependencies.
Which Hisense TV generations and firmware versions are supported?
The integration supports all major generations of Hisense VIDAA smart TVs: Modern VIDAA 2.0 (2024+, U6K/U7K/U8K), Middle VIDAA 1.5, Standard RemoteNOW Dynamic (2018–2023), and Legacy Static models (pre-2022). It includes an automatic 4-tier authentication fallback cascade.
Does the integration require cloud access or internet connectivity?
No. The integration operates with 100% local push control (iot_class: local_push). You can isolate your TV on a dedicated IoT VLAN with external internet access completely blocked, and Home Assistant will continue to control it seamlessly.
Can it turn the TV on when it is in standby?
Yes. It supports Wake-on-LAN with dual-MAC fallback (Ethernet and Wi-Fi) as well as standby token refresh for TVs that support Fast Power On / Quick Start.
Does it support other TV brands running VIDAA OS?
VIDAA OS is developed by the Hisense Group and licensed to partner OEM manufacturers (such as Toshiba, Loewe, and others). The underlying architecture and protocol are designed for the VIDAA platform.
